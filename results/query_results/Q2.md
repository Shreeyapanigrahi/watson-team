# Q2: Negative sentiment surface

**Question:** Which brand and geography pairs have an average HCP sentiment below 0.4 in active documents?

Run at 2026-10-28T20:02:51+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?brand ?geography (ROUND(AVG(?score) * 100) / 100 AS ?avgSentiment) (COUNT(?s) AS ?assertions)
WHERE {
  ?s a Watson:SentimentAssertion ;
     Watson:forBrand ?b ;
     Watson:forGeography ?g ;
     Watson:sentimentScore ?score ;
     Watson:derivedFrom ?chunk .
  ?chunk Watson:isChunkOf ?doc .
  ?doc Watson:lifecycleState "ACTIVE" .
  ?b rdfs:label ?brand .
  ?g rdfs:label ?geography .
}
GROUP BY ?brand ?geography
HAVING (AVG(?score) < 0.4)
ORDER BY ?avgSentiment
```
