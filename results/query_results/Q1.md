# Q1: Shared target discovery

**Question:** Which indications (counting their sub-indications) are targeted by two or more different drugs, and by which brands?

Run at 2026-10-28T20:02:51+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?indication (COUNT(DISTINCT ?drug) AS ?drugs) (GROUP_CONCAT(DISTINCT ?brandLabel; separator=", ") AS ?brands)
WHERE {
  ?brand a Watson:Brand ;
         rdfs:label ?brandLabel ;
         Watson:containsDrug ?drug ;
         Watson:targetedIndication ?narrow .
  ?narrow Watson:subIndicationOf* ?ind .        # transitive: EGFR-mutant NSCLC counts for NSCLC and for lung cancer
  ?ind rdfs:label ?indication .
}
GROUP BY ?indication
HAVING (COUNT(DISTINCT ?drug) >= 2)
ORDER BY DESC(?drugs) ?indication
```
