# Q7: Weakest recent sentiment by therapeutic area and region

**Question:** Since 2023, where is HCP sentiment weakest, by therapeutic area and region, and how many documents and brands stand behind it?

Run at 2026-10-28T20:02:55+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?therapeuticArea ?region
       (ROUND(AVG(?score) * 100) / 100 AS ?avgSentiment)
       (COUNT(DISTINCT ?brand) AS ?brands)
       (COUNT(DISTINCT ?doc) AS ?documents)
WHERE {
  ?s a Watson:SentimentAssertion ;
     Watson:sentimentScore ?score ;
     Watson:assertionDate ?date ;
     Watson:forBrand ?brand ;
     Watson:forGeography ?geo ;
     Watson:derivedFrom ?chunk .
  ?chunk Watson:isChunkOf ?doc .
  ?doc Watson:lifecycleState "ACTIVE" .
  ?brand Watson:inTherapeuticArea ?ta .
  ?ta rdfs:label ?therapeuticArea .
  ?geo Watson:partOfRegion? ?r .                # a country counts for its region; a region counts for itself
  ?r Watson:geographyKind "region" ; rdfs:label ?region .
  FILTER (?date >= "2023-01-01"^^xsd:date)
}
GROUP BY ?therapeuticArea ?region
ORDER BY ?avgSentiment
```
