# Q3: Sentiment trajectory

**Question:** Which brands had an average sentiment above 0.6 before 2023 and below 0.4 from 2023 on?

Run at 2026-10-28T20:02:51+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?brand (ROUND(?early * 100) / 100 AS ?avgBefore2023) (ROUND(?late * 100) / 100 AS ?avgFrom2023)
WHERE {
  ?b rdfs:label ?brand .
  { SELECT ?b (AVG(?score) AS ?early)
    WHERE { ?b Watson:hasSentiment ?s .
            ?s Watson:sentimentScore ?score ; Watson:assertionDate ?date ; Watson:derivedFrom ?c .
            ?c Watson:isChunkOf ?d . ?d Watson:lifecycleState "ACTIVE" .
            FILTER (?date < "2023-01-01"^^xsd:date) }
    GROUP BY ?b HAVING (AVG(?score) > 0.6) }
  { SELECT ?b (AVG(?score) AS ?late)
    WHERE { ?b Watson:hasSentiment ?s .
            ?s Watson:sentimentScore ?score ; Watson:assertionDate ?date ; Watson:derivedFrom ?c .
            ?c Watson:isChunkOf ?d . ?d Watson:lifecycleState "ACTIVE" .
            FILTER (?date >= "2023-01-01"^^xsd:date) }
    GROUP BY ?b HAVING (AVG(?score) < 0.4) }
}
ORDER BY ?brand
```
