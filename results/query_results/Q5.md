# Q5: Coverage gap

**Question:** Which indications have at least one brand but are covered by fewer than two active documents?

Run at 2026-10-28T20:02:52+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?indication (COALESCE(?n, 0) AS ?documents) (MIN(?brandLabel) AS ?exampleBrand)
WHERE {
  ?brand Watson:targetedIndication ?i ;
         rdfs:label ?brandLabel .
  ?i rdfs:label ?indication .
  FILTER NOT EXISTS {
    ?d1 Watson:mentionsIndication ?i ; Watson:lifecycleState "ACTIVE" .
    ?d2 Watson:mentionsIndication ?i ; Watson:lifecycleState "ACTIVE" .
    FILTER (?d1 != ?d2)
  }
  OPTIONAL { SELECT ?i (COUNT(DISTINCT ?d) AS ?n)
             WHERE { ?d Watson:mentionsIndication ?i ; Watson:lifecycleState "ACTIVE" }
             GROUP BY ?i }
}
GROUP BY ?indication ?n
ORDER BY ?documents ?indication
```
