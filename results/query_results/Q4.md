# Q4: Competitive snapshot (Oncology)

**Question:** In Oncology, which brands are compared with the most other brands in active competitive landscape documents?

Run at 2026-10-28T20:02:51+0530 on a graph of 5805 triples.

```sparql
PREFIX Watson: <http://watson.local/pharma#>
PREFIX rdf:  <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?brand (COUNT(DISTINCT ?rival) AS ?rivals) (GROUP_CONCAT(DISTINCT ?rivalLabel; separator=", ") AS ?comparedWith)
WHERE {
  ?ta rdfs:label "Oncology" .
  ?landscape a Watson:CompetitiveLandscape ;
             Watson:inTherapeuticArea ?ta ;
             Watson:describedBy ?doc ;
             Watson:includesBrand ?b .
  ?doc Watson:lifecycleState "ACTIVE" .
  ?b rdfs:label ?brand ;
     Watson:competesWithin ?rival .
  ?rival rdfs:label ?rivalLabel .
}
GROUP BY ?brand
ORDER BY DESC(?rivals) ?brand
```
